## 🎥 My YouTube Bookmarks – Chrome Extension


Never lose your favorite YouTube moments again.
This lightweight Chrome Extension lets you bookmark timestamps while watching videos, so you can instantly jump back to the parts that matter most.

✨ Features
- 🔖 Instant Timestamping
Save bookmarks with a single click while watching any YouTube video.
- 📂 Organized by Video
Manage multiple bookmarks per video — perfect for tutorials, lectures, or long-form content.
- ⏩ Quick Navigation
Jump directly to saved moments without scrubbing through the timeline.
- ☁️ Cloud Synced
Your bookmarks are stored using Chrome’s sync storage, so they follow you across devices.

🛠️ Built With
- HTML5 – Popup and options UI
- CSS3 – Styling and layout
- JavaScript (ES6+) – Core logic and Chrome APIs
- Chrome Extension APIs – Storage, tabs, and messaging

📦 Installation
- Clone or download this repository:
git clone https://github.com/Soumyadip-Mondal-2005/youtube-bookmarks-extension.git

Open Chrome and go to chrome://extensions/
- Enable Developer Mode (top right)
- Click Load unpacked and select the extension folder
- Start watching YouTube and saving your favorite moments!


🔑 Permissions Used
- tabs – To access YouTube video URLs
- storage – To save bookmarks across sessions
- activeTab – To interact with the current video
